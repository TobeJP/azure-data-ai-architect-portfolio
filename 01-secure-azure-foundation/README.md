# Project 01 — Secure Azure Enterprise Foundation

## Status

🚧 In Progress

## Scenario

NorthStar Enterprises is beginning its Azure adoption journey
and requires a secure, governed and scalable cloud foundation
for application, data and future AI workloads.

## Objectives

Design and implement an Azure environment that provides:

- Network segmentation
- Identity-based access
- Least-privilege RBAC
- Secure secrets management
- Infrastructure governance
- Centralized monitoring
- Cost accountability
- Infrastructure as Code
- Support for future data and AI workloads

## Technologies

- Microsoft Azure
- Microsoft Entra ID
- Azure Virtual Network
- Network Security Groups
- Azure Key Vault
- Azure Storage
- Azure Monitor
- Log Analytics
- Azure Policy
- Terraform
- GitHub
