# Lab 001 — Azure Resource Governance

## Business Problem
Octageo Global Services/NorthStar Enterprises lacks consistent Azure resource naming, ownership and cost-allocation standards.

## Objective
Establish and validate a basic Azure resource-management structure.

## Requirements
- Standard resource group naming
- Identifiable ownership
- Environment classification
- Cost centre allocation

## Solution Design
Use purpose-based Azure resource groups with a standard naming convention and mandatory governance tags.

## Implementation
Document the Azure Portal steps followed, the resources created and their configurations.

## Problem Reproduction
Create a resource group without required tags and identify the missing governance metadata.

## Resolution
Apply the required tags and verify the updated configuration.

## Test Results
Record expected results, actual results and pass/fail status.

## Evidence
Include sanitized screenshots showing the initial issue and corrected state.

## Lessons Learned
Explain what resource groups, tags and subscriptions contribute to Azure governance.

## Next Improvement
Implement Azure Policy to detect or prevent missing required tags.
